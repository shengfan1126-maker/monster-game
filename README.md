# 權能進化・魔物篇｜AI 接手說明

> 給要改這個遊戲的 AI 看的。請先讀完這份，再看使用者貼給你的那一份檔案。

## 這是什麼

手機瀏覽器玩的文字冒險遊戲，純前端（HTML＋JavaScript，沒有伺服器、沒有建置工具、沒有套件）。玩家是一隻轉生成哥布林的主角；**規則和數值由程式管，故事由玩家自選的語言模型（Gemini 或 OpenRouter 免費模型）寫**。用 GitHub Pages 放在網路上給幾個朋友玩。

## 檔案分工（照載入順序）

| 檔案 | 管什麼 | 適合誰改 |
|---|---|---|
| `index.html` | 頁面骨架、設定面板的按鈕、載入下面各檔、畫面上的版本號 | 小改可以 |

| `sys_prompt.js` | **敘事者指令 `SYS`**（語氣、文風、模型要回傳的 JSON 欄位）、組裝送給模型的內容 | 改語氣、措辭：免費 AI 可以；改 JSON 欄位：找 Claude |

## 一定要遵守

1. **改完要給整份檔案**，從第一行到最後一行，不能省略、不能寫「其餘不變」「…」。使用者會把你給的內容整份貼上取代原檔。
2. **只改被要求的地方**。其他程式碼、註解、空行原樣保留。
3. **全部 `.js` 共用同一個全域範圍**（一般的 `<script src>`，不是模組）：
   - 不要加 `import`／`export`、不要包成 `(function(){ ... })()`、不要加 `"use strict"`。
   - 別的檔案定義的函式和變數可以直接用（例如 `S`、`save()`、`render()`、`esc()`、`$()`）。
   - **新的頂層名字不能和別份檔案重複**，否則整個遊戲打不開。不確定就取一個特別一點的名字。
   - 檔案「一載入就執行」的程式碼（不在函式裡的那種），只能用到排在它前面的檔案的東西。一般只是加函式或改函式內容，不用擔心這條。
4. **存檔格式不能亂改**：
   - 遊戲狀態是全域物件 `S`，整個 `JSON.stringify(S)` 存在瀏覽器的 IndexedDB（資料庫 `mowu`、表 `kv`、鍵 `mowu_save_v2`），`localStorage` 同名鍵只當備用；玩家也會匯出成 .json 檔。
   - **不要改名、刪除、改型別**已經有的欄位（`S.hp`、`S.corpses`、`S.party`、`S.log` 等）。朋友手上的舊存檔會讀不進來。
   - 要加新欄位：在 `save.js` 的 `heal()` 裡補一行「沒有就給預設值」（例：`if(S.foo==null)S.foo=0;`），舊存檔讀進來時才會自動補上。
5. **語氣規範在 `sys_prompt.js` 的 `SYS`**：敘事者怎麼寫、用什麼文風、要回傳哪些 JSON 欄位都在這裡。改 JSON 欄位名稱時，`turn.js` 讀取它的地方要一起改——這種跨檔案的修改請交給 Claude。
6. 介面文字一律**繁體中文**，跟現有用語一致。
   - 種族用詞：goblin＝「哥布林」、hobgoblin＝「大哥布林」、gnome＝「諾姆」。**不要用「地精」「侏儒」**（程式會把模型寫的地精自動換成哥布林、侏儒換成諾姆）。
7. 不要在程式裡寫進任何金鑰，也不要接新的外部服務。

## 改完怎麼確認

- 打開遊戲網址，**等 1～10 分鐘再重新整理**（GitHub Pages 會快取）。
- 畫面全白、按鈕沒反應、出現奇怪錯誤 → 多半是語法錯誤或名字重複。到 GitHub 該檔案的「History」找到上一版，還原回去，再把錯誤情況告訴 AI。
- 要確認新版已經生效，可以順手改 `index.html` 裡的版本號（`<span class="sub">v0.25</span>`），看標題旁的版本號有沒有變。

- 主角技能沒有 Lv，只有等級字母 `g`（學到時的主角等級）；欄位 `box` 是 `act`（可用）或 `store`（倉庫），沒填當 `act`。同伴的技能也用等級字母 `g`（學到時的同伴等級），舊的 Lv 數字存檔由 `skillsFix` 轉成字母。

- 〈異香〉：可用技能第一次滿 9 格時覺醒（`checkAroma`）。
- 舊存檔：`skillsV026`（save.js）把 Lv 拿掉、技能全部變主角當時的等級，Lv 高的先進可用。
